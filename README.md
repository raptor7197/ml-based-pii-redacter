# Smart Redact

Smart Redact is a simple PII redaction app for documents and resumes.

## What it does
- Detects common PII like names, emails, phone numbers, and document text
- Redacts sensitive content
- Supports PDF input files

## Project layout
- `frontend/` UI assets
- `backend/` app logic
- `data/input_files/` sample input files

## Notes
- Keep uploads limited to files you want to redact
- Review the output before sharing it
